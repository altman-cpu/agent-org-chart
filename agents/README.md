# Custom agent packs

Custom or project-specific agents belong here. They are separate from `charts/`, which preserves the repository's source-grounded livestream org-chart catalog.

- [`satoshi-public-record-integration/`](./satoshi-public-record-integration/) — public-record Bitcoin research, scientific evidence review, read-only API contract mapping, and a local JSON Lines validation bridge.

Custom packs must state identity boundaries, tool permissions, network behavior, and whether integrations are live or contract-only. Never put secrets in manifests or tool payloads.
